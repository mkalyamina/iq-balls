# The IQ Balls

Головоломка на логику и пространство: уложите фигуры из шариков так, чтобы заполнить всё поле.

**Играть:** https://mkalyamina.github.io/iq-balls

На iPhone: откройте ссылку в Safari → «Поделиться» → «На экран „Домой“».

MVP-прототип (HTML). 40 уровней из книжки, 5 категорий сложности, подсказки, пропуск уровня. Покупки и реклама имитируются.
